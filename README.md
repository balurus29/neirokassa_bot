# Бот «Нейрокассы»

Автопостинг и бот в сообщениях для сообщества ВКонтакте «Нейрокасса» (club243319848).
Работает на GitHub Actions по будильникам cron-job.org — так же, как бот «Фактолавки».

## Что делает

| Задача | Когда (МСК) | Что публикует |
| --- | --- | --- |
| `morning` | 08:40 | Свежая новость про ИИ из RSS, пересказ через GigaChat + ссылка на источник |
| `day` | 12:40 | Практичный совет по теме недели |
| `evening` | 19:40 | Рубрика дня: Пн — нейросеть недели, Вт — промпт, Ср — как заработать, Чт — до и после, Пт — топ-5, Сб — опрос, Вс — итоги недели |
| `inbox` | каждые 15 мин | Отвечает на «Начать», «ГАЙД» и кнопки подборщика |

Темы недели меняются по кругу: тексты → картинки → видео → свой бот.

Партнёрские ссылки появляются только в рубриках Пн, Ср, Чт, Пт и в подборщике, только если
`MONETIZATION=1` и у оффера в `data/offers.json` заполнен `erid`. Без erid оффер не публикуется никогда.

## Установка

1. Создай на GitHub репозиторий `neirokassa_bot` и загрузи туда все файлы из архива.
   Лучше сделать его **публичным**: тогда минуты GitHub Actions бесплатны без лимита.
   Секреты при этом никто не увидит.
2. **Settings → Secrets and variables → Actions → Secrets**:
   - `VK_GROUP_TOKEN` — ключ сообщества (права: управление, сообщения, фото, документы);
   - `VK_USER_TOKEN` — ключ пользователя-админа для публикации на стене (получаем отдельно);
   - `GIGACHAT_AUTH_KEY` — ключ авторизации GigaChat (можно тот же проект, что у «Фактолавки»);
   - `PIXABAY_KEY` — тот же ключ Pixabay (необязательно).
3. Там же, вкладка **Variables**:
   - `DRY_RUN` = `1` на время проверки (посты печатаются в лог, ничего не публикуется);
   - `GUIDE_URL` — ссылка на статью-гайд в сообществе;
   - `MONETIZATION` = `0` (включить `1`, когда появятся офферы с erid).
4. Проверка: **Actions → Нейрокасса бот → Run workflow**, задача `evening`. В логе должен появиться текст поста.
5. Когда тексты устраивают — `DRY_RUN` = `0`.

## Будильники cron-job.org

Для каждой задачи — отдельное задание:

- URL: `https://api.github.com/repos/ТВОЙ_ЛОГИН/neirokassa_bot/actions/workflows/bot.yml/dispatches`
- Метод: `POST`
- Заголовки:
  - `Authorization: Bearer ТОКЕН_GITHUB` (fine-grained token с правом Actions: Read and write на этот репозиторий)
  - `Accept: application/vnd.github+json`
- Тело: `{"ref":"main","inputs":{"task":"morning"}}` — для остальных `day`, `evening`, `inbox`.
- Расписание: morning 08:40, day 12:40, evening 19:40, inbox каждые 15 минут (часовой пояс Europe/Moscow).

## Партнёрские офферы — `data/offers.json`

```json
[
  {
    "name": "Название сервиса",
    "category": "texts",
    "url": "https://сервис.ru/?ref=ТВОЙ_ID",
    "advertiser": "ООО «Название»",
    "erid": "Abc123XyZ",
    "pitch": "Что делает и для кого — одно предложение",
    "promo": ""
  }
]
```

`category`: `texts`, `images`, `video`, `study`, `bots` или `any`. Бот сам добавит в ссылку `subid`
(дата и рубрика — чтобы в кабинете партнёрки было видно, что приносит деньги) и `erid` последним параметром.

## Свои источники новостей — `data/feeds.json`

Список RSS-лент. Сломанная лента просто пропускается, бот не падает.
